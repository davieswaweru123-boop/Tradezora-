# TradeZora Dashboard Prototype

A standalone responsive frontend prototype for TradeZora, an independent third-party trading interface intended to integrate with Deriv.

## Run
Open `index.html` in a browser.

## Current prototype
- Responsive dark trading dashboard
- Market watchlist and search
- Demo chart area
- Trade panel with stake/payout interaction
- Demo UP/DOWN trade actions
- Automation toggle and safety controls
- Responsive mobile layout
- Independent-platform disclosure

## Next integration
Replace demo behavior with a secure backend and official Deriv OAuth/API integration. Do not collect Deriv passwords. Keep access tokens server-side and add explicit real-account confirmation and risk controls.
