# TradeZora Mobile Connect Fix

This package fixes the mobile dashboard so the **Connect Deriv** button is clearly visible below the top header.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Deriv login URL
The button opens:
`https://tradezora-backend-use-1.onrender.com/auth/login`

## Deploy
Upload/replace these three files in the `main` branch of the TradeZora GitHub Pages repository. GitHub Pages will publish the updated site automatically.
